# LLM 시대 개발자의 5계명

레주메/면접의 철학적 토대. LinkedIn About 의 도입부 ("Code is a punch card") 의 출처 narrative.

원본 50 라인. YouTube 강연 transcript 인용 형태로, 시간 인덱스(`<<n,n+1,...>>`) 가 본문에 박혀 있음.

## 1. LLM 시대 개발자의 마음가짐 — 5계명

| # | 한 줄 |
|---|---|
| 1 | **코딩은 천공카드와 같다** — 손으로 코드 작성하는 행위는 천공카드를 뚫는 것과 같다. 과거의 수동적 방식에 얽매이지 말라. |
| 2 | **자연어를 이해하지 못하는 앱은 장난감에 불과하다** — 자연어를 알아듣지 못하는 앱은 서비스가 아닌 toy. |
| 3 | **수동적 개발 방식은 개발을 하지 않는 것과 같다** — 수동으로만 작성하고 새로운 시도를 하지 않는 것은 개발을 하지 않는 것이다. |
| 4 | **아랫세대를 굶긴 윗세대에 대한 존경은 필요 없다** — 과거 방식만 고수하며 새로운 시도를 막는 윗세대에 존경 불필요. |
| 5 | **루프와 컴퓨터 사용은 기본이며, 그 너머를 찾아야 한다** — 루프/computer-use 는 frontier 가 아니라 floor. 그 이상의 가치를 찾아라. |

## 2. LLM 유저는 새로운 컴퓨팅이자 코딩이다

> 아무것도 시도하지 않는 사람은 아무것도 얻을 수 없다. 직접 해보지 않고 입으로만 말하는 사람들을 비판하며, 직접 시도하는 것이 중요하다.

## 3. 노력의 방향성 전환

| 핵심 | 내용 |
|---|---|
| 갇히지 말 것 | 30/40/50대 무관, 본인이 과거에 했던 방식만 고수하는 것은 노력이 아니다. |
| 직접 투자 | 직접 돈 투자하고 여러 번 시도하며 제품 만들면서 얻은 생각이 노력의 방향성을 다르게 만든다. |
| 이미 풀린 문제 활용 | 우리가 고민하는 문제는 이미 2-3년 전 미국/중국에서 시행착오 + 기술 리포트로 공개됨. |
| LLM 적용 + 직접 앱 | 리포트 → LLM 적용 → 결과 보면서 직접 앱 만들며 배우는 것이 효과적. |

## 5계명 → LinkedIn About 도입부 매핑
